# Ryan Reale AI Tool Portfolio

Static portfolio site: AI tools and automations for commercial real estate and finance workflows.

- `index.html`: landing page
- `projects/`: one case-study page per project
- `demos/leaseiq/`: LeaseIQ front-end demos (fictional sample data)
- `demos/property-portfolio/`: rental portfolio dashboard (fictional data)
- `demos/flyover/`: industrial building fly-over (imagery: Esri, Maxar, Earthstar Geographics)
- `demos/condo-tour/`: three.js condo walkthrough (textures and models from Poly Haven, CC0; three.js, MIT)

Demo data is fictional. Names, addresses and figures from real engagements have been removed.
